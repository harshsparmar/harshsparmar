### Things I've built

- **[TailorCV](https://github.com/harshsparmar/TailorCV)** ([live](https://tailorcv.harsh-p.dev)): AI resume optimizer. Reads a job description and rewrites a resume's summary and bullets to improve ATS keyword matching. Uses a fallback chain of four Groq-hosted LLMs and exports PDF/Word server-side with headless Chromium. *Next.js, TypeScript, Groq, Supabase, Puppeteer*
- **[SecureVault](https://github.com/harshsparmar/securevault-document-portal)** ([live](https://securevault.harsh-p.dev)): Document management system with role-based access control, private storage and time-bound signed URLs for previews. *Laravel, PHP, Docker, AWS S3*
- **[Logo Flow](https://github.com/harshsparmar/logo-flow)** ([live](https://logoflow.harsh-p.dev)): Real-time logo builder with Iconify vector icons and a React colour picker. *React, JavaScript, Iconify API*
